JSON (jq) Regex Search

Runs locally and offline; no CDN or external libraries required.

Comma-separated property paths. Nested fields can use dot notation.
This standalone utility is provided under the MIT License.
jq reference: jq 1.8.2 — source: jqlang/jq; jq is released under the MIT License.
Note: this offline version does not bundle jq or jq-web; the search is implemented in vanilla JavaScript and supports jq-style leading regex flags such as (?i), (?m), and (?s).
